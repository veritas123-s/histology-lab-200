# 医学形态学实验 200题

本次备考题库：180道选择题、20道简答题。依据用户指定7份PPT及2026年10月21日考试通知，覆盖四大基本组织、免疫系统、胃、小肠、肝、肺、肾和皮肤的观察内容；不限于作业。

简单练习直接认名称；标准练习覆盖完整200题并含结构描述。超纲题单独标示，只在主动选择时出现，永不进入正式模拟。

支持顺序与随机练习，名称题可切换填空。正式模拟每次随机抽12题，默认6选择、4名称填空、2简答，比例可调、总数须为12；同场不重复题号或图片，题目和题型位置一起混排。默认整场40分钟，30/60秒每题自动翻页为可选训练，不代表今年考试规定。

每题支持“举报／申请删除”。公共反馈打开GitHub Issue草稿，需登录并完成提交；维护者核实后修正或下架。本机屏蔽立即排除后续练习及新模拟，可在屏蔽名单恢复。公共题库不会因一个未核实的报告自动删除。

作答、错题及屏蔽名单保存在当前浏览器本机，不上传，不跨设备同步。公开文件不含原始个人报告、学号、内部日志或凭据。
