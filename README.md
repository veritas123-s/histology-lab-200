# 医学形态学实验 200题

组织学看图练习：180道五选一、20道简答。覆盖基本组织、免疫器官，以及胃、肠、肝、肺、肾和皮肤。

支持按章节顺序练习、全库200题随机练习、30/60秒计时、错题复习和简答自评。正式模拟每次从全库180道选择题中抽9道、20道简答题中抽1道，再混排全部10题，简答题可在任意位置。单次模拟题目不重复，不同题可能使用同一张图；各次模拟独立抽取。

作答保存在当前浏览器本机，不上传。手机可以直接使用GitHub Pages页面。

题目为新编练习，参考学生往年回忆及课程材料，不代表官方真题或当前正式考试范围。实验报告仅作为线索；答案经过独立AI审阅，尚未由课程教师审定。

图像来自所给课程材料及大学组织学图谱，具体来源见题目解析。图片版权归原作者，本仓库不为第三方图片授予新的使用许可。

公开文件仅包含运行页面、必要题图和本说明。
